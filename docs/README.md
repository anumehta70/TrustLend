# Submission assets

Populate this folder before submitting, per the Level 4 checklist:

- `screenshot-product-ui.png` — landing + borrower dashboard
- `screenshot-mobile.png` — borrower dashboard at a mobile viewport
- `screenshot-analytics.png` — PostHog dashboard showing tracked events
  (`wallet_connected`, `payment_history_synced`, `loan_originated`,
  `feedback_submitted`)
- `demo-video-link.md` — link to the recorded walkthrough
- `deployment.md` — deployed `CONTRACT_ID`, `TOKEN_CONTRACT_ID`, and a list
  of the 10+ onboarded wallets with their transaction hashes (from
  `GET /api/users` and `GET /api/loans/borrower/:wallet`)
- `feedback-summary.md` — export of `GET /api/users/feedback`
